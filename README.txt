FEATHERHARVEST — Organic Bird Seed Mix Website
=============================================
Static multi-page responsive website.

Pages:
- index.html — Home (exactly 6 main sections after the hero/navigation)
- products.html — Seed Mixes (3 content sections)
- nutrition.html — Nutrition Guide (3 content sections)
- about.html — About Us (3 content sections)
- contact.html — Contact (3 content sections)

Features:
- Responsive mobile navigation
- Visible active navigation menu state
- Button and card hover effects
- High-resolution remote imagery with object-fit: contain for product/content images
- No framework or build step required
- Open index.html in a browser to preview

Design direction:
Inspired by the supplied Agricom organic/agriculture theme and eFlux grocery/ecommerce structure, but implemented as an original FeatherHarvest concept rather than copying the referenced themes.
